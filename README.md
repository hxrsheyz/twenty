# C++ Concept Programs

A collection of 20 simple C++ programs demonstrating five fundamental programming concepts.

## Topics Covered

### 1. Arrays
- Sorting an array
- Finding the second-largest element
- Transposing a matrix
- Reversing an array

### 2. Enumerations (Enums)
- Traffic control system
- Order tracking
- Day transitions
- Access control

### 3. Structures
- Calculating the area of a rectangle
- Student ranking system
- Library book search
- Comparing two dates

### 4. Pointers
- Addition using pointers
- Swapping two numbers
- Sorting an array using pointers
- Finding the largest element using pointers

### 5. Unions
- Employee information
- Sensor readings
- Storing student marks
- Product measurements

## Requirements
- A C++ compiler, such as GCC
- Visual Studio Code (recommended)

## How to Run
Compile a program using:

Compile a program using:

    g++ sorting.cpp -o sorting

Run it on Windows PowerShell using:

    .\sorting.exe

Replace `sorting.cpp` with the filename of the program you want to run.

## Purpose
This project is intended for learning, practicing, and understanding basic C++ programming concepts.
